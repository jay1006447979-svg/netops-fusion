NetOps Fusion 架构文档

网络配置管理工具：支持华为 / H3C / 锐捷 / 迈普 4 厂商的交换机、路由器、AP 配置生成、推送、备份与文件传输服务。

1. 技术栈与启动

  • 后端：FastAPI + SQLAlchemy(async) + SQLite(aiosqlite)，Python 虚拟环境 C:/Users/User/.workbuddy/binaries/python/envs/netops（已装 pyftpdlib）
  • 前端：原生 HTML/JS/CSS 单页应用，无框架无构建，由 FastAPI 静态托管
  • 启动（开发端口 8000，Windows 下不要用 --reload，改代码必须手动重启）： 
    "C:/Users/User/.workbuddy/binaries/python/envs/netops/Scripts/python.exe" -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --app-dir "D:/WorkBuddy/NetWorkFig/netops-fusion/backend"
  • 重启规范：Get-CimInstance Win32_Process 匹配 python+uvicorn → 温和 Stop-Process（不要 -Force，防孤儿 socket 占端口）→ 等 3 秒 → 后台重启

7. 前端要点（static/）

  • index.html：8 个页面（总览 dashboard、配置生成 config、设备管理 devices、拓扑图 topology、网络工具箱 tools、厂商手册 manual、模板 templates、笔记 notes），通过 nav-item 的 data-page 切换（支持 ?page=xxx 深链接，另有外链 /docs）。拓扑图页逻辑独立在 static/topology.js，画布用 AntV X6（已本地化到 static/vendor/，不依赖 CDN）
  • app.js：约 2200 行，所有逻辑在一个 IIFE 里，window.App 暴露 onclick 所需函数（新按钮必须在这里导出）。表单收集用 collectFormConfig（仅收集 enable=true 的块），回填用 fillFormFromConfig（缺失字段设 'false'），页面初始化调 resetConfigForm() 保持表单空白

8. 关键约定（修改前必读）

  • 所有配置类的 enable 字段默认 False：后端 Field(False,...) + 厂商生成器 if xxx.get("enable", False) + 前端下拉默认"否"
  • 设备配置顶层字段用 interface（单数）；VLAN 列表前端收集 name 字段；华为/华三用 description 命令，锐捷/迈普用 name 命令
  • Windows 下 TFTP 的坑：Proactor 事件循环里 UDP addr 是 IPv4 映射 4 元组需规范化；create_datagram_endpoint 必须带 local_addr=("0.0.0.0", 0)；本机跑 Tftpd64 会抢占 69 端口
  • 强杀 uvicorn（taskkill /F）会产生孤儿 socket 占死端口，只能重启电脑释放 —— 永远温和停止
  • 备份数据双写：DB 是唯一事实来源，.cfg 是副本；删记录走 API 会同步删文件，手动删文件后网页会标记缺失并可恢复

9. 常见修改场景指南

想做什么要动的地方（自上而下）
新增一个配置功能块① app/models/ 加 Pydantic 模型（enable 默认 False）→ ② 四个 app/vendors/*.py 各加生成逻辑 → ③ config_routes.py 接收 → ④ index.html 加表单块 → ⑤ app.js 的 collectFormConfig / fillFormFromConfig / resetConfigForm 同步
新增页面/功能页① index.html 加 section + nav-item → ② app.js 加加载与渲染函数并导出到 window.App → ③ 需要接口时在 app/api/ 新建路由文件并在 main.py 注册
新增厂商支持① app/vendors/ 新建文件继承 base.py → ② registry 注册 → ③ 前端厂商下拉加选项
改数据库表结构改 models.py + 在 base.py 的 init_db 里加对应 ALTER TABLE 迁移（SQLite 轻量迁移，不动旧数据）
