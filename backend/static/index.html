启动后在设备上直接传输备份文件（把下方 IP 换成本机地址）：
TFTP 拉取配置（华为/H3C）— 直接用文件名即可，服务端会自动在设备子目录中查找： tftp <本机IP> get SW1_20260914_213000.cfg flash:/SW1.cfg
也可带设备目录：tftp <本机IP> get SW1/SW1_20260914_213000.cfg flash:/SW1.cfg
TFTP 上传配置（自动保存到 uploads/ 目录）： tftp <本机IP> put flash:/vrpcfg.zip SW1_vrpcfg.zip
FTP 拉取配置： ftp <本机IP> → 匿名登录（anonymous）或 netops / netops（可读写）→ cd SW1 → get SW1_20260914_213000.cfg
注意：只能下载服务端已存在的备份文件（不能 get 设备上的文件名）；本机若运行了 Tftpd64 等其他 TFTP 程序会抢占端口导致启动失败
